## Projeto em destaque

### [EletroStock](https://github.com/mvrtinswho/eletrostock)

Sistema de controle de estoque de materiais elétricos, desenvolvido como trabalho final de Desenvolvimento Web com Python e Django.

- Aplicação web e aplicativo mobile conectados à mesma base de dados.
- Cadastro de materiais, categorias e fornecedores.
- Controle de entradas e saídas, histórico e alertas de estoque mínimo.
- API JSON com autenticação por token.
- Testes das regras de estoque e da autenticação.

**Tecnologias do projeto:** Python, Django, SQLite, JavaScript, React Native e Expo.

[Explorar o código](https://github.com/mvrtinswho/eletrostock) · [Arquitetura e decisões técnicas](https://github.com/mvrtinswho/eletrostock/blob/main/docs/arquitetura.md)
